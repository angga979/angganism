# Angganism

**Poetry & AI Writing Companion**

Angganism adalah aplikasi personal poetry karya Muhammad Alghazali.

## Phase 1

- Flutter Android app
- Dark coffee-brown poetry aesthetic
- Home
- Poetry archive
- Poem reader
- AI Writer UI
- About
- GitHub Actions APK build
- Backend skeleton

## Phase 2

- OpenAI Responses API
- Secure backend deployment
- Flutter → backend connection
- AI writing companion

## Build

```bash
flutter pub get
flutter run
```

APK release:

```bash
flutter build apk --release
```

GitHub Actions juga akan otomatis membuat artifact APK setiap push ke `main`.
