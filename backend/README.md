# Angganism Backend

Backend ini akan menjadi perantara antara aplikasi Flutter dan OpenAI.

## Menjalankan lokal

```bash
npm install
cp .env.example .env
npm start
```

Jangan pernah memasukkan `.env` atau `OPENAI_API_KEY` ke GitHub repository.

Phase 1 hanya menyiapkan backend. Deployment dan koneksi Flutter akan dilakukan pada Phase 2.
